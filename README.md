# Como executar o projeto

## 1. Instale as dependências

Na raiz do projeto, execute:

```bash
npm install
```

## 2. Inicie o projeto

Depois que a instalação terminar, execute:

```bash
npx expo start
```

3. Execute no dispositivo ou emulador

Após iniciar o Expo, você poderá:

Escanear o QR Code com o aplicativo Expo Go no celular.

Pressionar a para abrir no Android Emulator.

Pressionar i para abrir no iOS Simulator (macOS).

Pressionar w para abrir no navegador.

Pré-requisito: tenha o Node.js instalado antes de executar os comandos.
